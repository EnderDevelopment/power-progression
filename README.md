# Power Progression

Power Progression is a Minecraft plugin that enhances player progression through a power system. Players start at power 5 and can increase or decrease their power based on kills and deaths. Each power level affects the player's walking speed, sprinting speed, attack damage, and health. This plugin is designed to add a strategic and dynamic element to Minecraft gameplay.

## Install

1. Download the plugin JAR file from the [releases page](https://github.com/EnderDevelopment/PowerProgression/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to enable the plugin.

## Use

1. Players start with a power level of 5.
2. Players lose 1 power level when they die.
3. Players gain 1 power level when they kill another player.
4. Power levels are capped between 1 and 10.
5. Use the `/power` command to check your current power level.
